Django Blog Application



This project includes:

- User Registration & Login
- Create Blog Posts
- Comment on Posts
- One Upvote Per User
- Admin Panel


- 🔐 User Authentication (Register / Login / Logout)
- ✍️ Authenticated users can create blog posts
- 👍 One upvote per user (Many-to-Many relationship)
- 💬 Comment system
- 🛠 Django Admin support
- 🌏 Timezone configured for Asia/Kolkata

---

 Tech Stack:

- Python 3
- Django 6
- SQLite (default database)
